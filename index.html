Featured Projects

cybershield-ai

CyberShield AI is a Gmail security and threat-intelligence project designed to help users identify and understand email-based security risks such as phishing, suspicious links, scams, malicious attachments, and exposed credentials. The website provides features including AI phishing detection, malicious attachment scanning, breach exposure monitoring, a real-time threat timeline, a security advisor, Gmail OAuth, a security dashboard, and an admin dashboard. Users can enter a Gmail address or use the Gmail connection interface to start a security scan and receive a security score, detected threats, breach information, and recommended security actions. The current version is mainly a demonstration/prototype, and the website itself states that the Gmail scanning, Gmail connection, and breach results are simulated rather than accessing a real inbox.

Movie Matrix

Movie Matrix is a movie discovery and recommendation platform designed to help users easily find movies based on their interests, preferences, genres, ratings, and other movie information. The project provides a user-friendly interface where users can explore movies, view details such as titles, genres, ratings, descriptions, and release information, and discover movies that match their interests. It can also be enhanced with a recommendation system that suggests similar or personalized movies, making it easier for users to choose what to watch. The main goal of Movie Matrix is to create a simple, attractive, and intelligent platform that combines movie information, search, filtering, and personalized recommendations in one place.
